Benchmarking brain-connectivity prediction

Papers that predict cognitive scores from resting-state functional connectivity often report strong effects, usually from small samples evaluated with leave-one-out cross-validation. This project re-runs those methods on larger cohorts under one shared, leakage-safe protocol, to measure how large the effects are when every method is evaluated the same way.

The second aim is practical. Each reproducibility check is usually a one-off script that re-implements cross-validation, harmonisation and reporting. The project packages that work as a reusable harness, mm-neuro, so the same evaluation can be pointed at a new cohort, target or pipeline by changing a configuration file.

Cohorts and targets

ADNI
Older adults across the Alzheimer's spectrum (cognitively normal, mild cognitive impairment, dementia), multi-site, one resting-state scan per person. Targets: MMSE and ADAS-Cog13.
ABIDE-I
Autism and typically developing participants from many sites. Targets: full-scale, verbal and performance IQ, and diagnosis. Used to test whether the harness transfers to a different domain.
OASIS-3
A second Alzheimer's cohort with MMSE and the Clinical Dementia Rating, being added as an independent test.

Functional connectivity is the only predictive input. The T1 scan is used only for registration; no structural features enter any model.

Preprocessing

The main pipeline keeps the functional data in each person's native space and moves the atlas instead:

  1. T1: bias-field correction, deep-learning skull stripping (HD-BET), affine registration to MNI space.
  2. fMRI: dummy volumes dropped, rigid motion correction, brain mask.
  3. Rigid registration of the mean fMRI image to the person's T1.
  4. The Schaefer-200 atlas, first aligned to the project's template, is warped into each person's fMRI space, and one time series is taken per region.
  5. Denoising: white-matter and CSF signals plus five aCompCor components, detrending, 0.01–0.1 Hz band-pass, and censoring of high-motion volumes.
  6. Connectivity: Pearson correlation between all region pairs, Fisher-z transformed.

The same scans are also processed with three widely used alternatives, to measure how much the choice of preprocessing changes connectivity:

PipelineMain steps
DeepPrepfMRIPrep-style motion correction, coregistration and normalisation to MNI; motion, WM/CSF and aCompCor regression; band-pass; motion censoring
SPM12 + CONNCONN's default MNI preprocessing; default denoising with aCompCor and ART scrubbing; ROI-to-ROI connectivity
FSL + ICA-AROMAMCFLIRT, slice-timing correction, boundary-based and nonlinear registration to MNI, smoothing, ICA-AROMA, WM/CSF regression, band-pass

All four end in the same atlas and the same set of connections, so differences come from preprocessing alone. Agreement is measured within subject, per connection (ICC), per network block, for group differences and for residual motion effects.

These are compared with simple baselines (cohort mean, ridge regression, gradient-boosted trees, demographics only) and with the project's own encoders (an MLP on connectivity, and graph neural networks). Where a paper's exact setup can be matched, a faithful variant is run as well, with the original atlas, target and leave-one-out cross-validation.

Evaluation protocol

Fixed splits
Five-fold cross-validation with versioned split files; every subject is tested exactly once, and folds are stratified by diagnosis (ADNI) or site (ABIDE).
No leakage
Site harmonisation (ComBat) and any group-level features such as ICA are fitted on the training subjects of each fold only. The validation set is used only to choose hyperparameters. Unit tests check that no test subject reaches these steps.
Leave one site out
On ABIDE, each sufficiently large site is held out in turn, so the model is tested on a scanner and population it has never seen.
Sample size
Repeated random subsamples at the original studies' sample sizes and a sweep over sample sizes, with method and protocol held fixed, show how much estimates vary at small N.
Statistics
Corrected resampled t-tests for paired fold comparisons, permutation tests on the correlation of pooled predictions, and bootstrap confidence intervals on explained variance.

Software

The whole evaluation runs through mm-neuro, an open, configuration-driven harness. Its design, configuration format and components are described on the software page.

A first paper from this work, Scan–Rescan Reliability of Individualized Network Attribution in Resting-State Functional MRI, is accepted for oral presentation at BVM 2027. A paper on the benchmark and the harness is in preparation. Results will be added here once they are published.
