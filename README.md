# sheethalb.github.io

Personal research website of Sheethal Bhat (Pattern Recognition Lab, FAU Erlangen-Nürnberg), served by GitHub Pages
at https://sheethalb.github.io.

Plain static HTML, no build step: edit the `.html` files or `assets/style.css`, commit, push to `main`; the site
updates within a few minutes.

Content rule: research pages describe aims and methods only. Results are added after they are published.
